# 🛡️ cpp-network-dlp

> Visual Studio 2022 환경에서 `agy cli` 멘토링을 받으며 진행하는 7일 완성 C++ 네트워크 데이터 유출 탐지 프로젝트

---

## 📌 1. 프로젝트 소개

클라이언트와 서버가 통신할 때 오가는 텍스트 데이터를 확인하여, 주민등록번호나 민감한 정보가 포함되어 있는지 실시간으로 검사하고 차단하는 네트워크 보안(DLP) 프로그램입니다.

C 언어와 Java의 기본 지식을 바탕으로, 7일 동안 Visual Studio 2022 환경에서 C++을 배우며 `agy cli`를 통한 페어 프로그래밍 방식으로 개발합니다.

---

## 🛠️ 2. 개발 환경

* **언어**: C++
* **개발 도구 (IDE)**: Visual Studio 2022
* **멘토링 도구**: `agy cli`

---

## ✨ 3. 주요 기능 목표

1. **TCP 소켓 통신**: 클라이언트가 전송하는 데이터를 서버에서 수신
2. **다중 접속 처리**: 여러 클라이언트가 동시에 접속해도 멈추지 않고 처리 (멀티스레드)
3. **개인정보 탐지**: 수신된 데이터 안에서 주민등록번호 같은 민감한 패턴 검사
4. **차단 및 기록**: 유출 의심 데이터 발견 시 즉시 연결을 끊고 파일(로그)로 기록

---

## 📅 4. 예상 7일 개발 일정

* **Day 1**: Visual Studio 2022 세팅 및 기본 C++ 소켓 통신 만들기
* **Day 2**: 여러 명이 동시 접속할 수 있게 멀티스레드 적용하기
* **Day 3**: 텍스트 안에서 주민번호나 기밀 키워드를 찾는 검사 로직 만들기
* **Day 4**: 유출 감지 시 접속 강제 종료 및 로그 파일 저장 기능 만들기
* **Day 5**: 코드 정리 (메모리 누수 확인 및 C++ 기본기 다듬기)
* **Day 6**: Wireshark 도구로 데이터가 실제로 차단되는지 눈으로 확인하기
* **Day 7**: 전체 코드 점검 및 프로젝트 정리
